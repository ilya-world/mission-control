# Mission Control

Mission Control — браузерный планировщик задач с деревом задач и списком активных действий.

## Запуск

### Локально

Откройте `index.html` в браузере. Данные хранятся в `localStorage` и сохраняются автоматически.

### В режиме предпросмотра

Если нужно открыть проект через локальный сервер (например, для предпросмотра в окружении Codex),
запустите простой статический сервер:

```bash
node server.js
```

По умолчанию он слушает `http://localhost:3000` (порт можно переопределить через `PORT`).
